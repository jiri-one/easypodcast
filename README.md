# EasyPodcast

A simple self-hosted podcast system for one listener: a small Go server and a Flutter app for
Android and Linux, made for e-ink screens. Episodes stream straight from the publisher. The server
keeps the subscriptions, the episode lists, the positions and what has been played, so listening
moves between devices without losing the place.

Status: in development.

## Repository

- `server/` – the Go server and its container image
- `app/` – the Flutter app for Android and Linux
- `docs/` – the specification (in Czech), the architecture contract and the GUI mockups
